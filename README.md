One-line office joke: an employee nods so hard through the 4 p.m. all-hands that their badge photo updates itself — and HR still uses it for the performance review. Written for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the joke to `/output/entry.txt` — 130 characters, one line, UTF-8, no trailing newline. No network, no randomness: two runs write byte-identical files. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere for local testing.
